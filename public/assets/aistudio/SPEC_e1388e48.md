# SPEC.md — Contrat Fonctionnel et Technique (Ouest Dynamics V2)

## 1. Périmètre & Architecture Cible
- **Prototypage UI & IA (Google AI Studio)** : React 19 + TypeScript strict + Tailwind CSS + SDK `@google/genai` (`gemini-2.5-flash` avec `responseSchema`).
- **Production Cible (Migration Next.js 15 App Router)** : Rendu hybride SSG/ISR (Core Web Vitals : LCP < 1.8s, CLS = 0, INP < 100ms), API Route Handlers sécurisés et persistance sur **Supabase (PostgreSQL + RLS + Storage)**.

## 2. Catalogue & Moteur Tarifaire (`pricing-engine`)
Tarifs de base indicatifs (en `XOF`, convertibles dynamiquement en `EUR` et `USD`) :
- `BRANDING` (Pôle 1 — Identité & Brand Book 360°) : Fourchette `950 000` – `2 400 000 XOF` (Délai : 10–15 jours ouvrés)
- `WEB` (Pôle 2 — Plateforme Web / E-Commerce / SaaS) : Fourchette `1 500 000` – `4 500 000 XOF` (Délai : 15–25 jours ouvrés)
- `MOBILE_DESKTOP` (Pôle 3 — Application iOS/Android/Desktop Offline-First) : Fourchette `2 800 000` – `7 500 000 XOF` (Délai : 25–40 jours ouvrés)
- `GROWTH` (Pôle 4 — Acquisition Paid Media, SEO/GEO & Tracking CAPI) : Fourchette `750 000` – `2 000 000 XOF` (Délai : 7–14 jours ouvrés)
- **Modificateurs Transverses** :
  - `TRANSVERSE_DA` (Direction Artistique Executive & Design Tokens W3C) : `+20 %`
  - `TRANSVERSE_AI` (Intégration Agents IA Gemini / Automatisations n8n ZDR) : `+25 %`
  - `FAST_TRACK_48H` (Mobilisation Guilde Élastique sous 48h) : `+15 %`
  - **Remise Multi-Pôles** : `-10 %` automatique si >= 2 Pôles sélectionnés simultanément.

## 3. User Stories & Critères d'Acceptation (Given / When / Then)

### US-01 : Estimation Multi-Devises Transparente
- **Given** un visiteur sur l'étape 3 du Configurateur de Brief ayant sélectionné `WEB` + `TRANSVERSE_AI`,
- **When** il bascule la devise globale de `XOF` vers `EUR` dans la Navbar ou le Configurateur,
- **Then** toutes les fourchettes budgétaires et les 3 tranches de paiement (`40 %`, `30 %`, `30 %`) se recalculent instantanément selon `1 EUR = 655.957 XOF` sans perte d'état du formulaire.

### US-02 : Qualification par Concierge IA & Pré-remplissage
- **Given** un prospect décrivant son projet en langage naturel dans le Concierge IA (*« Nous lançons une fintech à Abidjan et il nous faut une identité de marque, une app mobile iOS/Android et une landing page »*),
- **When** le modèle Gemini retourne sa réponse structurée (`responseSchema`),
- **Then** l'interface affiche la synthèse stratégique ainsi qu'un bouton *« Pré-remplir mon brief »* qui coche automatiquement `BRANDING`, `WEB`, `MOBILE_DESKTOP`, sélectionne la devise appropriée et pré-remplit le résumé du projet dans le Configurateur.

### US-03 : Conformité Consentement ARTCI / RGPD
- **Given** un premier visiteur arrivant sur la plateforme,
- **When** il clique sur *« Personnaliser »* dans la bannière CMP et valide uniquement les cookies essentiels,
- **Then** les scripts marketing/tracking restent désactivés (Google Consent Mode v2 `denied`) et un reçu d'audit horodaté est enregistré.

## 4. Clauses de Gouvernance Affichées & Appliquées
1. **Propriété des Actifs Clients** : Domaines, hébergements, comptes Stores et Business Managers restent au nom du client.
2. **Cession de Propriété Intellectuelle** : Cession intégrale après paiement du solde.
3. **Validation Tacite** : 5 jours ouvrés sur chaque jalon livré.
4. **Confidentialité IA** : Traitement sous politique Zero-Data Retention (ZDR).
